
# Employee and Department Microservices

## Project Overview
A microservices project developed using Java and Spring Boot.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST APIs
- Postman

## Services
- Employee Service: Manages employee details.
- Department Service: Manages department details.

## Features
- CRUD operations
- Input validation
- Exception handling
- MySQL database connectivity

Completed
